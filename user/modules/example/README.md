# Example

The canonical ChAoS MVC instructional user Module for developers learning current Module development.

## Version

2.0.0

## Purpose

Example is executable reference code. It demonstrates:

- normal Controller → Model → View structure;
- authenticated Module administration;
- database lifecycle state detection;
- fresh SQL installation;
- exact-version SQL migration;
- module-owned Data Delete;
- explicit Data Reset;
- canonical reference data;
- Create, Read, Update, and Delete operations;
- validation;
- CSRF-protected POST mutations; and
- visible success and failure status.

Open `/example` for the public explanation and `/admin/example` for the working administrative demonstration.
